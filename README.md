# Dream House — expediente maestro

Repositorio de diseño y control integral para una **warehouse house / loft industrial
residencial en Boyacá, Colombia**. La intención es construir una única nave
industrial-residencial extraordinaria donde vivienda, taller RC/DIY, tecnología y un
carro proyecto formen una sola arquitectura.

## Estado actual

**Fase:** definición consolidada y anteproyecto dimensional; todavía no constructivo.  
**Fecha de corte documental:** 11 de agosto de 2026.  
**Base de estudio:** nave de 18,00 × 36,00 m, PB de 648 m² y P2 posterior parcial de
aproximadamente 270 m²; área construida conceptual aproximada de 918 m².  
**Bloqueador principal:** no existe predio exacto ni estudios técnicos del sitio.  
**Alerta económica:** el target activo de construcción v0.2 es aproximadamente
$988,05 M COP, pero reemplaza un orden de magnitud v0.1 de $4,3–4,8 B COP. La diferencia
no está validada con cantidades, ingeniería ni cotizaciones comparables.

## Principio rector

> Una caja + una estructura + un gran vacío + luz + objetos técnicos bien organizados
> + una pared final.

El lujo debe provenir de proporción, altura, luz, paisaje, silencio, estructura,
detalle y desempeño; no de formas gratuitas ni revestimientos superpuestos.

## Regla de seguridad y responsabilidad

Este repositorio sirve para concebir, coordinar, preguntar, comparar y controlar el
proyecto. **No sustituye** estudio geotécnico, topografía, levantamiento, concepto de uso
del suelo, licencia, diseños firmados, memorias de cálculo, revisión independiente,
presupuestos contractuales, dirección o supervisión técnica de obra. Ningún documento
marcado como conceptual o preliminar es apto para construir.

## Convención de documentos

Cada documento derivado debe declarar:

- estatus: borrador, activo, congelado, sustituido o histórico;
- fecha de corte y versión;
- fuente o decisión que lo origina;
- supuestos y asuntos abiertos;
- responsable de aprobación cuando el equipo profesional exista.

Las decisiones se registran; no se sobrescriben sin historia.
