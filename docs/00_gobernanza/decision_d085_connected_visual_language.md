**Version:** 0.1

**Status:** owner-authorized graphic/software implementation for connected review  
**Source:** owner's instruction to implement the researched visual-language plan, following the 2026-10-03 audit.

## Decision

Implement the [visual-language plan](../08_investigacion/connected_svg_visual_language_audit_and_plan_2026_10.md)
through the existing Python generators. Use the warm technical atlas direction, portable
literal SVG styling, separate information/material/study/finding/selection roles, visible
local legends and purpose-specific architectural/coordination navigation. Selection uses
cobalt independently of amber OPEN evidence and violet study geometry.

The owner authorizes implementation and review of the graphic proposal. This is not a
claim that the owner has completed the subsequent reading tasks, approved construction
plotting or adopted a new physical design. SVG-G0's implementation direction is recorded
here; pilot/rollout evidence and remaining acceptance tasks are recorded in the
[implementation record](../06_gestion_y_obra/connected_visual_language_implementation_2026_10.md).

## Invariants and publication

- Geometry, source values, quantities, findings and stable entity IDs retain their meaning.
- OPEN and FAIL evidence remains discoverable; graphic cleanup cannot close a conflict.
- SVGs remain generated outputs; the reader has no geometry-editing capability.
- Historical generators, versioned drawings and `docs/BORN_Legacy/` remain unchanged.
- Connected review releases and README review previews may receive the new presentation.
  The 27 adopted drawing aliases remain a separate publication lineage. Future alias
  promotion requires a traceable new issue and catalog update; it is not implicit here.
- Material and wall-family colours in native consumers keep source-specific meanings;
  never reinterpret a hue as a check result solely because it matches a palette token.
- Fit-to-page review printing makes no numerical scale or construction-legibility claim.

No construction scope or cost baseline changes arise from this graphic implementation.
Physical design, procurement, engineering acceptance and existing conflicts retain their
current gates.
